# Dataset

This project uses the CNRPark+EXT dataset for smart parking occupancy detection.

## Dataset Information

- Dataset: CNRPark+EXT
- Purpose: Parking-space occupancy detection
- Used for: Smart car parking simulation and evaluation
- Main label: `occupancy`
- The dataset contains parking-camera observations and occupancy information.

## Usage in This Project

The dataset is processed by the Java simulation to provide parking occupancy information for the proposed fog-computing-based smart parking system.

## Dataset Source

The original CNRPark+EXT dataset should be obtained from its official source and used according to its applicable license and terms.

> The complete third-party dataset is not redistributed in this repository.
